# Security Policy

## Supported Versions

We provide security updates for the latest release on the `main` branch.

## Reporting a Vulnerability

If you discover a security vulnerability within Excel Agent, please do not open a public issue.

Instead, please send an email to security@excelgen.app with:
- Description of the vulnerability
- Steps to reproduce
- Potential impact

We will respond promptly to acknowledge receipt and work with you to coordinate a responsible fix and disclosure.
